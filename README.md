# Love Connect - Fullstack

Love Connect - Dating app with Discover swipe, Moments, Chat Rooms, Private messages, Verification and Paystack premium

Live site: https://love-connect9.onrender.com

Features:
- Discover with swipe cards
- Moments short videos
- Chat Rooms (group) and Private messages (WhatsApp voice notes)
- Likes & Matches
- Account verification (phone OTP + photo selfie)
- Premium: Free, Monthly N2000, 3 months N5000, Yearly N15000 with Paystack

Tech: MERN - MongoDB, Express, React, Node.js + Socket.io
